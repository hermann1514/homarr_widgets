# Changelog – Claude Usage

Alle nennenswerten Änderungen an diesem Widget werden in dieser Datei dokumentiert.

Das Format orientiert sich an [Keep a Changelog](https://keepachangelog.com/de/1.1.0/),
die Versionierung an [Semantic Versioning](https://semver.org/lang/de/).

## [1.0.0] – 2026-11-07

### Hinzugefügt
- Erste Version: Session-Limit (5 h), Wochenlimit aller Modelle und Wochenlimit pro Modell als Balken mit Tempo-Vergleich, Countdown und Reset-Zeitpunkt.
- Balken für Extra Usage, nur wenn aktiviert, und Hinweis bei API-Fehlern der Integration.
- Daten aus Home Assistant über die Integration hass-claude-usage. Optionen für das Präfix der Sensoren und das Modell-Limit.
- Eigene [README](README.md) mit Einrichtung von Integration und Token.
